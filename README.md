## 📝 Penugasan Mahasiswa

1. **Tugas 1 (21.9.2026) — Perancangan Struktur Navigasi SIMSKK:**
   - Analisis mendalam sistem informasi kegiatan kemahasiswaan (SIMSKK ITENAS).
   - Diagram hierarkis navigasi 5 level interaktif.
   - Dokumentasi laporan HTML dan PDF resmi.

2. **Tugas 2 (28.9.2026) — Analisis SDLC & Portofolio Web Interaktif:**
   - Studi komparasi metode *Software Development Life Cycle* (Waterfall, Agile, Spiral, Prototype).
   - Implementasi rancangan portofolio personal responsif.
   - Laporan kajian teknis format PDF.

3. **Tugas 3 (05.10.2026) — Desain Portofolio Web Responsif & Styling CSS:**
   - Pengembangan antarmuka web CV & Portofolio personal dengan elemen semantik HTML5.
   - Penerapan sistem desain *Dark Theme* modern berbasis CSS kustom murni (Flexbox, CSS Grid, tipografi Google Fonts, dan *media queries* responsif).
   - Dokumentasi laporan bukti pengerjaan resmi format PDF (`152025013_Adika_Faza_Athallah_tugas_3.pdf`).

4. **Tugas 4 (12.10.2026) — Penguasaan Tata Letak & Styling CSS Lanjutan:**
   - Implementasi styling CSS modular dengan arsitektur HTML & CSS terpisah maupun gabungan.
   - Dokumentasi laporan pengujian tampilan web responsif format PDF (`152025013_Adika_Faza_Athallah_tugas_4.pdf`).

5. **Tugas 5 (19.10.2026) — Operasi CRUD 1 Tabel PHP & MySQL:**
   - Implementasi backend berbasis PHP dan MySQL untuk sistem pengelolaan data satu tabel (*Studi Kasus: Aplikasi Catatan Keuangan*).
   - Operasi lengkap: **Create** (`tambah.php`, `proses_tambah.php`), **Read** (`index.php`), **Update** (`ubah.php`, `update.php`), dan **Delete** (`hapus.php`).
   - Tampilan bersih berbasis Bootstrap 5 dan koneksi database prosedural (`koneksi.php`).
   - Dokumentasi laporan resmi format PDF (`152025013_Adika_Faza_Athallah_Tugas_CRUD_1_Tabel.pdf`) serta modul panduan pembelajaran mandiri di folder `docs/`.
