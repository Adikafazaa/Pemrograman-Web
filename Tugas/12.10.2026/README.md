# Tugas 4 — Latihan & Course W3Schools (HTML & CSS)

Tugas praktikum mata kuliah **IFB-211 Pemrograman Web** (Pertemuan 12 Oktober 2026).  
Menyelesaikan dan mendokumentasikan serangkaian modul latihan interaktif resmi pada platform pembelajaran web **W3Schools** untuk topik dasar HTML dan CSS.

---

## 📋 Rincian 12 Modul yang Diselesaikan

### Modul HTML (6 Topik):
1. **HTML Basic Exercises** — Struktur dokumen dasar HTML5 (`<!DOCTYPE html>`, `<html>`, `<body>`, dsb).
2. **HTML Elements Exercises** — Penggunaan tag elemen HTML, tag bersarang (*nested elements*), dan penutup tag.
3. **HTML Attributes Exercises** — Penggunaan atribut umum (`href`, `src`, `width`, `height`, `alt`, `style`).
4. **HTML Headings Exercises** — Tingkatan judul dokumen (`<h1>` sampai `<h6>`).
5. **HTML Paragraphs Exercises** — Penataan paragraf `<p>`, pemisah baris `<br>`, dan garis horizontal `<hr>`.
6. **HTML Styles Exercises** — Penerapan atribut *inline style* (`color`, `background-color`, `font-size`, `text-align`).

### Modul CSS (6 Topik):
7. **CSS Introduction Exercises** — Konsep dasar sintaks aturan CSS (Selector, Property, Value).
8. **CSS Syntax Exercises** — Penulisan selector dan blok deklarasi menggunakan tanda kurung kurawal `{}`.
9. **CSS Selectors Exercises** — Pemilihan elemen berbasis Element Selector, ID Selector (`#id`), Class Selector (`.class`), dan Grouping.
10. **CSS How To Exercises** — Tiga metode penyisipan CSS (External, Internal, dan Inline CSS).
11. **CSS Comments Exercises** — Penulisan komentar pada berkas CSS (`/* komentar */`).
12. **CSS Colors Exercises** — Penerapan nilai warna berbasis Color Names, RGB, HEX, dan HSL.
