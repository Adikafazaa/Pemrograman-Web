# Tugas 5 — CRUD 1 Tabel PHP & MySQL

Aplikasi catatan keuangan berbasis web sederhana yang mengimplementasikan operasi CRUD (*Create, Read, Update, Delete*) menggunakan PHP dan MySQL.

### Cara Menjalankan:
1. Nyalakan MySQL di Laragon / XAMPP dan import basis data [`keuangan.sql`](keuangan.sql).
2. Jalankan server lokal: `php -S localhost:8000`
3. Buka di peramban: `http://localhost:8000/index.php`
